# 📊 股票分析智能体 · 全维度 v3

> 500 天 K线 · 双数据源 · 30+ 指标 · 价位预测 —— 单文件网页版，打开即用

输入股票名称与当日行情数据，自动生成全维度技术分析报告。v3 版本集成均线系统、动量指标、MACD 状态判断与关键价位预测。

## 功能

- **指标矩阵**：MA5/10/20/60/120/250 均线系统、RSI(6)/(14)、MACD 状态、20日线方向
- **行情输入**：当前价、昨收、最高最低、成交量、换手率、总市值、市盈率
- **双数据源**：支持手动输入与自动拉取两种模式
- **价位预测**：支撑位 / 压力位 / 目标位预测
- **500 天 K 线**：长周期趋势可视化

## 使用方法

双击 `index.html` 用浏览器打开即可，建议使用 Edge / Chrome。

> v3 为单文件网页版；另有带后端服务的 v3_server 版本可自动拉取实时行情。
